I'm Jotham Teo — a quantitative researcher with a background in finance and
software engineering, currently completing an MSc in Quantitative Finance.

This blog exists for one reason: to do quantitative research **rigorously and
honestly**, in public.

### What you'll find here

- **Empirical research.** When a popular claim can be tested, I test it. I
  report what the data actually shows, including null results and effects that
  are weaker than the literature suggests.
- **Methodology explainers.** Event studies, factor models, options
  microstructure, time-series tests — written for someone who wants to *use*
  the methods, not just hear about them. Intuition first, then the maths,
  then code.
- **Practitioner notes.** Honest accounts of using modern tools (including AI
  agents) in real research workflows — where they help, where they fail, and
  how to keep the pipeline reproducible.

### What you won't find here

- Backtests with no transaction costs.
- Strategies presented without their failure modes.
- Numbers that can't be reproduced from public data and the linked code.
- Hype.

### Reproducibility

Every empirical post links to the analysis code on
[GitHub](https://github.com/jothamteo). Where possible, the code runs on a
free Python install with public data sources — no proprietary feeds, no
vendor dependencies.
